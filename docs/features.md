# الميزات وطريقة عملها

## المرضى

زر **تسجيل مريض** يفتح الاسم والهاتف وتاريخ الميلاد والجنس، ثم القسم والجناح والسرير المتاح. يتغير اختيار الأسرة حسب القسم والجناح. يتحقق الخادم من توفر السرير داخل المعاملة نفسها؛ لا يمكن لجهازين حجز السرير نفسه.

مطابقة الاسم وتاريخ الميلاد تنبّه إلى ملف سابق. يلزم سبب موثق قبل استخدام الملف المطابق، وتُرفض الهوية المختلفة أو الإقامة المفتوحة بالفعل. الملاحظة اختيارية عند التسجيل العادي. هذه مطابقة مساعدة وليست تحققًا رسميًا من الهوية؛ الموظف مسؤول عن التحقق.

فتح بطاقة المريض يعرض الإقامة والخدمات والمواد والدفعات. يمكن نقل المريض إلى قسم أو جناح أو سرير آخر مع السبب. إضافة مادة تخصم مخزونها وتضيف تكلفتها في معاملة واحدة. يُحفظ سعر الخدمة وقت إضافتها؛ تغيير السعر لاحقًا لا يغيّر فواتير سابقة. لا توجد رسوم إقامة تلقائية؛ تُضاف كخدمة معرفة بواسطة المدير.

إلغاء بند يتطلب سببًا وصلاحية مالية، ويحفظ السجل ويرد كمية المادة. يمنع الإلغاء الذي يخلق رصيدًا دائنًا بعد الدفع. لا تعدّل الإقامة المغلقة.

## الفواتير والتحصيل

تبويب الفواتير يعرض التحصيل والمصروف وصافي الحركة النقدية؛ **الصافي ليس حساب أرباح محاسبيًا**. يسجل المحاسب أو المدير المصروف بعنوان وتصنيف ومبلغ وتاريخ ومرجع اختياري. إلغاء مصروف متاح للمدير مع السبب، دون حذف الأصل.

رابط **التحصيل والمغادرة** يفتح صفحة مخصصة. يمكن تحصيل دفعة جزئية مع إلغاء اختيار إنهاء الإقامة، أو تسديد الرصيد كاملًا وإنهاء الإقامة وإخلاء السرير. تُرفض الزيادة عن الرصيد. تتوفر طباعة الكشف والإيصالات، مع إعادة التحقق من الجلسة عند طلب الطباعة. يجب حماية المطبوعات وحذف ملفات PDF المصدّرة حسب سياسة المنشأة.

إعادة إرسال العملية بالمفتاح نفسه لا تسجل دفعة ثانية. عند انقطاع الشبكة لا تعتبر رسالة الخطأ دليلًا على فشل الدفع؛ أعد المحاولة بالمدخلات نفسها أو راجع سجل الدفعات قبل تحصيل مبلغ جديد.

## المخزون

إضافة مادة تتطلب رمزًا فريدًا واسمًا ووحدة وسعرًا وحد تنبيه. تبدأ الكمية بصفر. **حركة** تسجل توريدًا أو سحبًا مع السبب؛ لا يمكن الوصول إلى كمية سالبة. **السجل** يعرض آخر 50 حركة. تعديل السعر لا يغير بنود المرضى القديمة. يمكن أرشفة المادة ذات الرصيد الصفري، مع الاحتفاظ بتاريخها. المصروف والتوريد سجلان منفصلان؛ تسجيل مصروف لا يزيد الكمية تلقائيًا.

## الإدارة والوصول

يظهر زر حذف بجانب كل موظف وخدمة وسرير وقسم وجناح، مع نافذة تأكيد أو إلغاء. حذف الموظف ينهي جلساته ويطلب كلمة مرور المدير، باستثناء حساب المدير التجريبي المحلي. لا يمكن حذف الحساب الحالي أو آخر مدير فعّال، أو سرير مشغول، أو قسم يحتوي على أجنحة، أو جناح يحتوي على أسرة. تبقى الرسوم والمدفوعات ومواقع الإقامات السابقة وسجل التدقيق محفوظة بعد الحذف.

تبويب الإدارة يظهر للمدير فقط، ويضم الموظفين والخدمات والأسرة والأقسام والأجنحة والتدقيق. يمكن إنشاء الأقسام والأجنحة مستقلّة ثم ربط الأسرة بها، وتعديل الأسماء والارتباطات. تتحدث مواقع الإقامات المفتوحة عند تعديل الموقع، وتبقى مواقع الإقامات المغلقة محفوظة. إنشاء موظف يمنحه كلمة مرور مؤقتة يجب تغييرها. يمكن تعديل بياناته ودوره؛ تغيير الدور أو تعطيل الحساب يلغي جلساته. تغيير كلمة المرور يلغي جميع جلسات الحساب. استرجاع حساب المدير إجراء محلي للمسؤول المخوّل بواسطة `account:recover`، دون بريد أو خدمة سحابية.

| الدور              | ما يستطيع فعله                                                |
| ------------------ | ------------------------------------------------------------- |
| مدير              | جميع الميزات والإعدادات والتدقيق                              |
| أمين مستودع       | المواد وحركات المخزون دون بيانات المرضى أو المصروفات          |

## التحديث والأرقام والنماذج

كل الأجهزة تتصل بخادم واحد عبر شبكة المستشفى. يرسل الخادم إشعار تحديث خاليًا من بيانات المرضى، فتجلب الأجهزة البيانات وفق صلاحياتها، عادة خلال نحو `1.5` ثانية. الشبكة المحلية مطلوبة؛ لا توجد كتابة مستقلة أثناء انقطاعها. يظهر انقطاع التحديث بوضوح.

اللغة عربية فقط، اتجاه RTL وأرقام `0–9`، والعملة ليرة سورية. المبالغ تحفظ بوحدات صغيرة صحيحة في PostgreSQL لتجنب أخطاء الفاصلة العائمة. يعالج Zod المدخلات على الطرفين، ويعرض الخطأ بجانب الحقل وفي ملخص يمكن الانتقال منه للحقل. تظهر حالة الحفظ ويُمنع تكرار الضغط أثناء التنفيذ.
